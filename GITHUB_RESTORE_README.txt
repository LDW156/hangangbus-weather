한강버스 GitHub Pages 복구본

용도
- 인증 프로젝트의 site/public 폴더를 GitHub에 덮어써 화면이 깨졌을 때 복구용입니다.
- 종합대시보드 및 상세페이지는 v92.5 원본을 그대로 사용합니다.
- home.html만 전체 8개 선착장 메인 홈 v4입니다.

중요
- 이 복구본에는 실제 Cloudflare 인증 기능이 없습니다.
- GitHub Pages에서는 /home.html로 메인 홈을 확인할 수 있지만, 실제 인증 강제는 Cloudflare Worker 주소에서만 동작합니다.
- 보안 포털 프로젝트의 site 폴더를 GitHub에 다시 덮어쓰지 마십시오.
