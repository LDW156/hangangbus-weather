# 잠수교 수위 그래프 자동축 수정 v42

## 수정 내용
- 기존 고정 Y축 3.50~4.70m 제거
- 실제 관측 최저·최고 수위를 기준으로 Y축 자동 계산
- 주의 4.10m, 운항불가 4.46m 기준선은 항상 그래프 안에 포함
- 실제 수위가 3.50m 미만이어도 선이 차트 아래로 잘리지 않음
- 실제 수위가 4.70m를 넘어도 차트 위로 잘리지 않음
