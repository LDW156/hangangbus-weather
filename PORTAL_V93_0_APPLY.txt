한강버스 포털 구조 정상화 v93.0

이번 버전의 핵심은 URL 구조입니다.

/index.html      = 메인 홈 + 로그인 게이트
/dashboard.html  = 기존 v92.5 종합 상황 대시보드
/detail.html     = 전체 상세 모니터링
/analysis-*.html = 데이터 분석

기존 home.html 주소는 index.html로 자동 이동합니다.
모든 상세/분석 페이지의 좌측 메뉴에는 메인 홈과 종합 대시보드가 별도 항목으로 표시됩니다.
로그인 전 직접 상세 URL 접근 시 index.html로 돌려보냅니다.

주의: 현재 ID/PW는 UI 흐름 검증용입니다. 실제 인증은 Worker + D1 사용자관리 단계에서 구현합니다.

배포 순서
1. 이 전체 폴더를 GitHub 저장소 루트에 덮어쓰기
2. dashboard.html이 실제로 생겼는지 확인
3. 기존 index.html이 새 포털 홈으로 바뀌었는지 확인
4. Pages 배포 완료 후 repair.html?v=93.0 1회 접속
5. 그 다음 저장소 루트 URL을 열면 메인 홈이 나와야 합니다.
