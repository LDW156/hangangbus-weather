한강버스 v93.2 - 사용자 제공 메인보드 구성 기준

GitHub 저장소 루트에 이 ZIP의 파일을 전부 덮어쓰기.

핵심
- 제공한 메인보드 구성 이미지와 동일한 3열 배치 구조로 재구성
- 잠수교: 7.30m 기준 게이지 + 최근 추이
- 팔당댐: 방류량 추이 + 동부 2,000 / 서부 3,000 기준선
- 강수: 미니 막대 그래프
- 풍속: 원형 게이지
- 상황 이벤트: 5개 카드
- 좁은 화면에서는 1250px 이하부터 1열로 재배치하여 겹침/가로폭발 방지
- 풍향·풍속 1시간 후/2시간 후 카드의 기온 완전 제거
- 현재 기온만 유지
- 공통 좌측 메인화면 버튼 및 상단 계정 영역 포함

인증 관련
- GitHub Pages 주소(ldw156.github.io)는 공개 정적사이트이므로 F5로 직접 접속되는 것이 현재 구조상 정상입니다.
- 실제 로그인 세션 확인/로그아웃은 workers.dev에서만 동작합니다.
- 다음 단계에서 Worker를 GitHub 소스와 연결해 GitHub 수정이 그대로 보안포털에 반영되도록 고정해야 합니다.
